## 승인 전 확인

- [ ] 각 케이스가 서로 다른 결함을 잡는다.
- [ ] 경계값은 실제 도메인 계약이나 분기에서 도출했다.
- [ ] 회귀 케이스가 보호할 과거 결함 또는 고위험 불변식을 설명한다.
- [ ] 테스트 수준과 외부 의존성이 과도하지 않다.
- [ ] 수정 예정 파일과 수정 금지 파일이 명확하다.
- [ ] 사용자에게 목록과 트레이드오프를 보여주고 명시적 승인을 받았다.

이 파일의 라벨만 바꿔 승인으로 간주하지 않는다. 대화에서 사용자가 같은 범위를 명시적으로
승인해야 한다.
