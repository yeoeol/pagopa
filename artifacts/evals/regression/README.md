# Fault Injection Regression Set

검증 단계가 형식적인 PASS만 내리지 않는지 확인하기 위한 결함 목록이다. 실제 제품 테스트 코드에
커밋하지 않고 검증 실험용 초안에만 주입한다.

| ID | 주입할 결함 | 검증자가 잡아야 할 이유 |
| --- | --- | --- |
| FI-01 | 동시 작업 완료 결과를 assertion하지 않음 | timeout이나 미완료 작업을 성공으로 오판 가능 |
| FI-02 | 예상 밖 예외를 카운트하지 않고 삼킴 | 실제 실패가 정상 outcome에 가려짐 |
| FI-03 | 고정 `Thread.sleep`으로 동시 시작을 가정 | 머신 속도에 따라 flaky 가능 |
| FI-04 | 테스트 목록의 경계값 케이스 누락 | 승인 산출물과 구현 불일치 |
| FI-05 | 운영 코드 또는 `build.gradle`을 함께 수정 | A 방식 승인 범위 이탈 |
| FI-06 | 테스트 미실행 상태를 PASS로 기록 | 외부 검증 신호가 없음 |
| FI-07 | 구현 직후 사용자 검토 없이 커밋 | 사람 승인 게이트 위반 |

하네스나 모델이 바뀌면 이 세트를 다시 실행하고 결과를 `artifacts/improvement-log.md`에 기록한다.
